# 디자인 원본

Claude Design 프로젝트에서 가져온 화면들이다. 앱의 색·간격·타이포는 여기 적힌 값을
그대로 옮겨 쓴다 — `graphcalc/ui/theme.py` 의 토큰이 이 파일들의 oklch 값을
sRGB 로 옮긴 것이고, 주석에 원래 표기를 남겨 두었다.

| 파일 | 무엇 |
| --- | --- |
| `새 디자인 - 수학 탐구 계산기.dc.html` | 지금 앱이 따르는 디자인 (머티리얼 + 세리프 수식체) |
| `현재 UI - 데스크톱 앱.dc.html` | 갈아엎기 전의 데스크톱 앱 |
| `현재 UI - 해집합 계산기.dc.html` | 갈아엎기 전의 웹판 (`legacy-web/`) |
| `github.md` | 프로젝트와 저장소를 맞춘 기록 |

## 디자인에서 앱으로 옮길 때 달라진 것

- **글꼴**. 디자인은 Source Serif 4 를 부른다. 그대로 함께 넣되, 이 글꼴에는
  `∈` `ℤ` `aₙ` 의 아래첨자가 없어서 STIX Two Text 와 DejaVu Serif 를 뒤에 이어
  두었다 (`assets/fonts/README.md`).
- **모서리와 그림자**. `border-radius: 20px` 와 두 겹 그림자는 Qt 에서
  스타일시트와 QGraphicsDropShadowEffect 한 겹으로 옮겼다.
- **어두운 테마**. 디자인에는 밝기 전환 단추만 있고 어두운 판은 없다. 같은 말씨로
  어두운 짝을 새로 골랐고, 그래프의 여덟 색도 검은 바탕에서 읽히도록 다시 골랐다.
