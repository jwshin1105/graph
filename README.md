# 해집합 계산기

> 등고선 알고리즘을 보완해 **곡선뿐 아니라 점열(고립해)까지** 그리고,
> 나온 해와 함수에서 **수학적 규칙성을 스스로 찾아 주는** 웹 그래프 계산기.

의존성 없는 순수 ES 모듈 + Canvas 2D. 빌드 과정이 없고, 정적 파일만 띄우면 바로 돌아갑니다.

```bash
npm run serve     # http://localhost:8080
npm test          # 159개 테스트
```

---

## 1. 왜 만들었나 — 등고선법의 한계

GeoGebra 를 비롯한 대부분의 계산기는 음함수 `f(x,y)=0` 을 **균일 격자 marching squares**
(등고선 추적)로 그립니다. 격자 칸의 네 꼭짓점에서 `f` 의 부호가 달라지면 그 칸을 곡선이
지난다고 보고 선분을 잇는 방식입니다. 빠르고 튼튼하지만, 원리상 **세 가지를 놓칩니다.**

| 놓치는 것 | 예 | 왜 놓치나 |
|---|---|---|
| **고립해 (점열)** | `x² + y² = 0`, `sin²x + sin²y = 0` | 해 주변에서 `f ≥ 0` 이라 부호가 바뀌지 않음 |
| **접하는 해** | `(x²+y²−1)² = 0` | 곡선 전체가 중근이라 부호 변화가 없음 |
| **점근선** | `y = 1/x`, `y = tan x` | 극점을 사이에 두고 부호가 뒤집혀 **없는 곡선**을 그림 |

이 계산기는 이 세 가지를 정면으로 처리합니다.

## 2. 해집합 엔진 (`src/engine/implicit.js`)

### 2-1. 2단 적응 격자

화면을 약 14px 크기의 성긴 격자로 훑어, **해가 지날 가능성이 있는 칸만** 10×10 으로
세분합니다. 활성 칸을 모두 같은 배율로 나누므로 이웃 칸과 모서리 표본이 정확히 일치하고,
쿼드트리 방식에서 생기는 **T-접합 틈이 원천적으로 없습니다.**

칸을 활성화하는 조건은 두 가지입니다.

* 네 꼭짓점의 부호가 엇갈린다 (보통의 곡선)
* `min|f| ≤ |∇f|·h` — 부호는 안 바뀌지만 해가 스칠 만큼 `f` 가 작다

### 2-2. 점근선 판별 — 가짜 곡선 걸러내기

모서리 양 끝값 `v₁, v₂` 의 부호가 다르면 보통 그 사이에 근이 있습니다. 하지만 극점이
끼어 있어도 부호는 뒤집힙니다. 둘을 가르기 위해 **모서리 중점값을 한 번 더 계산**해서
선형성을 검사합니다.

```
매끄러운 영점 근처:  f 는 거의 선형  →  f(중점) ≈ (v₁+v₂)/2
점근선을 사이에 둠 :  f 가 폭발      →  |f(중점) − (v₁+v₂)/2| ≫ |v₁−v₂|
```

`|f(중점) − 평균| > 0.35·|v₁−v₂|` 이면 그 교차점을 버립니다. `|v₁−v₂|` 로 정규화하는 것이
핵심입니다 — 한쪽 값만 10¹⁶ 로 튀는 경우까지 잡아냅니다.

### 2-3. 고립해(점열) 복원

부호 변화가 없어 선분이 하나도 안 나온 칸 중에서, **격자 위에서 `|f|` 가 국소 최소가 되는
칸**만 골라 Nelder–Mead 로 파고듭니다.

> 기울기 기준(`min|f| < |∇f|·h`)만 쓰면, 해가 칸 한가운데에 정확히 놓였을 때
> 유한차분 기울기가 0 이 되어 버려 오히려 해를 놓칩니다. `|f|` 의 국소 최소 판정이
> 그 빈틈을 메웁니다.

찾은 점은 세 관문을 통과해야 해로 인정됩니다.

1. `|f(p)|` 가 주변 표본값의 10⁻⁶ 배 미만 — 실제로 해가 맞다
2. **각 방향에서 양옆의 부호가 같다** — `f(p+h)` 와 `f(p−h)` 의 부호가 갈리면
   그 방향으로 곡선이 지나간다는 뜻이지 고립해가 아니다
3. 두 배율(칸의 12%·3%)에서 모두 그렇다 — 한 배율만 보면 표본 간격에 속는다

처음에는 `|∇f(p)| ≈ 0` 인지로 걸렀는데, `y = tan x` 를 넓게 보면 극점의 큰 값이
기울기 비교의 기준을 부풀려 곡선 위의 점이 새어 들어왔습니다. **방향별 부호**로
바꾸니 곡선·view 조합 110가지에서 오탐이 0 이 되었고, 동시에
`y² = x²(x−0.1)` 처럼 **곡선에서 0.05 밖에 안 떨어진 고립해까지** 찾아냅니다
(예전에는 0.3 이 한계였습니다).

후보 칸을 고를 때도 **곡선이 지나간 이웃 칸은 견주지 않습니다.** 그러지 않으면
곡선 옆에 붙은 고립해가 곡선 쪽 칸에 가려 후보에서 빠집니다.

### 2-4. 해의 종류별 표현

| 입력 | 해의 모양 | 표현 |
|---|---|---|
| `x² + y² = 4` | 1차원 곡선 | 폴리라인 |
| `sin²x + sin²y = 0` | 0차원 점열 | 점 (π 격자 15개) |
| `y² = x²(x−1)` | 곡선 + 고립점 | 폴리라인 + 점 |
| `(x²+y²−1)² = 0` | 접하는 곡선 | 조밀한 점열 → 분석기가 `x²+y²−1=0` 로 복원 |
| `sin x = 0` | 실직선 위의 점열 | 점 (등차수열) |
| `P_n = (n, 2^n); 1<=n<=8` | 직접 만든 점열 | 점 + 규칙 분석 |
| `x²+y²=4 and y=x²−1` | 연립해 | **대입해서 1변수로** → 뉴턴법 정련 |
| `sin x=0 and cos x=−1` | 한 변수 연립 | 각 식의 근을 구해 **공통근**만 남김 |
| `x+y=3 and x−y=1 and 2x+y=4` | 과결정 연립 | 모든 쌍의 교점을 **전체 식으로 재검증** → 해 없음 |
| `x²+y²=4 ∧ x>0` | 조건이 걸린 곡선 | 등식은 그리고 부등식은 **제한**으로 (반원) |
| `x²+y²=4 or y=x` | 합집합 | 각 해집합을 따로 그려 합침 |
| `y < x² − 2` | 2차원 영역 | 반투명 채우기 + 점선 경계 |
| `x² + y² = −1` | 공집합 | **"해 없음"** 이라고 밝힘 (조용히 빈 화면을 두지 않음) |

### 2-4-1. 연립방정식은 되도록 대입해서 푼다

`y = f(x)` 처럼 한 쪽으로 풀린 식이 끼어 있으면 나머지 식에 **대입해서 1변수 방정식**으로
만듭니다. 두 곡선을 각각 추적해 교점을 찾는 것보다 훨씬 빠르고 정확합니다
(`x²+y²=4 ∧ y=x` 기준 100ms → 3ms). 양쪽 다 음함수일 때만 교점 추적으로 돌아갑니다.

### 2-4-2. 등식에 부등식이 붙으면 영역이 아니라 곡선이다

`x² + y² = 4 and x > 0` 은 반원입니다. 그런데 "부등식이 하나라도 있으면 영역"이라고
읽으면 `x²+y²=4` 를 만족하는 격자점이 없어 **빈 화면**이 나옵니다. 등식이 함께 있으면
등식은 그리고 부등식은 제한으로 씁니다 — `{ }` 문법과 정확히 같은 뜻입니다.
등식이 여럿이면(`x²+y²=4 ∧ y=x ∧ x>0`) 연립해를 구한 뒤 조건으로 거릅니다.

종류는 **조건을 떼어 낸 본래 식**에서 정확히 읽고 *"원의 일부"* 라고 적습니다.
표본을 맞춰 본 판정은 한 단계 낮춰 *"원 위에 놓입니다"* 라고만 합니다 —
`max(x, y) = 1` 은 두 직선 위에 놓이지만 해집합은 그 일부(ㄱ 자)일 뿐이기 때문입니다.

### 2-5. 정직하게 물러서는 경우

`sin x = 0` 을 x ∈ [−10⁶, 10⁶] 로 놓고 보면 해가 60만 개쯤 됩니다. 표본 간격보다 해가
촘촘하면 화면에 찍히는 점은 **전체 해의 일부를 성기게 집은 것**일 뿐이라, 그 간격으로
"공차"를 말하면 틀립니다. 이럴 때는 규칙을 만들어 내는 대신 *"해가 화면 해상도보다
촘촘합니다 — 확대해서 다시 보세요"* 라고 알립니다.

### 2-6. 곡선 표본화

`y = f(x)` 는 화면 좌표에서 **현으로부터 중점이 벗어난 거리**가 반 픽셀 아래로 떨어질
때까지만 재귀 세분합니다. 여기에 세 가지 장치를 얹었습니다.

* **불연속 절단** — `y` 가 화면 높이의 1% 이상 건너뛰면서, 그 변화가 **한쪽 절반에 몰려
  있으면**(반으로 쪼개도 간격이 안 줄면) 불연속으로 보고 선을 끊습니다. `floor x`,
  `sgn x` 의 계단과 `tan x` 의 극점이 모두 여기에 걸리고, 아주 가파를 뿐 연속인
  `sin(1/x)` 는 걸리지 않습니다(변화가 양쪽에 절반씩 나뉘므로).
* **없앨 수 있는 구멍은 메운다** — `sin x / x` 의 `x = 0` 처럼 한 점만 값이 없고 양옆이
  매끄럽게 이어지면 선을 끊지 않고 이어 그립니다. 진짜 극점(`1/x`)과는 구분됩니다.
* **앨리어싱 방지** — 화면상 간격이 넓게 남으면 중점이 우연히 현 위에 놓여도 더 나눕니다.
* **화면 밖 절약** — 두 끝점이 모두 보이는 영역 바깥이면 세분을 멈춥니다.
  (`y = x³ − 3x` 의 표본 수가 14,000 → 3,200 으로 줄었습니다)

매개변수·극좌표 곡선도 같은 방식으로 적응 표본화하며, **범위를 스스로 정합니다.**

* `r = 1+cos θ` → `[0, 2π]` (닫힌 곡선)
* `r = θ` → 주기가 없으므로 `[0, 8π]` 로 여러 바퀴
* `(t, t²)` → 닫히지 않으므로 `[−4π, 4π]`
* 직접 지정도 됩니다: `r = θ; 0 <= θ <= 2π`

## 3. 규칙성 분석 엔진 (`src/analysis/`)

해를 구하는 데서 끝내지 않고, **구한 해를 다시 입력으로 삼아** 규칙을 찾습니다.

```
sin x = 0  →  해 {−2π, −π, 0, π, 2π}  →  수열 분석  →  "공차 π 인 등차수열, xₙ = πn − 3π"
```

### 3-1. 수열 (`sequence.js`)

차례로 시험하고, 찾은 규칙마다 **일반항·다음 항 예측·확신도**를 붙입니다.

| 검사 | 방법 | 결과 예 |
|---|---|---|
| 등차 · 다항식 | 계차표에서 k계 차분이 상수 → 뉴턴 전진차분 공식 전개 | `aₙ = ½n² + ½n` |
| 등비 | 연속비가 일정 | `aₙ = 2·3ⁿ⁻¹`, 무한합까지 |
| 등차등비 | `aₙ₊₁ = r·aₙ + d` 최소제곱 후 검증 | `aₙ = 2·2ⁿ⁻¹ − 1` |
| 선형 점화식 | Hankel 계 최소제곱으로 최소 차수 k 탐색 → **특성방정식을 Durand–Kerner 로 풀어 닫힌 꼴 복원** | 피보나치 → `aₙ = √5/5·φⁿ − √5/5·((1−√5)/2)ⁿ` |
| 주기 | 최소 주기 탐색 | `aₙ = aₙ₊₃` |
| 알려진 수열 | 소수·카탈란·계승·삼각수·메르센 등 사전 대조 (인덱스 이동 허용) | "메르센 수와 일치" |
| 근사 모형 | 위에서 못 찾으면 함수족 적합 | `R² = 0.9999 인 삼각 모형` |

중근·복소 특성근도 각각 `(A+Bn)rⁿ`, `ρⁿ(A cos nθ + B sin nθ)` 꼴로 적어 줍니다.
**규칙이 없으면 억지로 만들지 않습니다** (`[3,1,4,1,5,9,2,6]` → 아무 규칙도 보고하지 않음).

### 3-2. 갈래 등차수열

`sin 2x = 1/2` 의 해처럼 **한 줄로는 등차가 아니지만 여러 등차수열이 번갈아 놓인**
경우를 잡아냅니다. 인덱스를 mod m 으로 쪼개 각 갈래가 같은 공차인지 보고,
대표항은 절댓값이 가장 작은 항으로 골라 교과서와 같은 꼴로 적습니다.

```
그래프에서 읽은 교점 x 좌표
  -23π/12, -19π/12, -11π/12, -7π/12, π/12, 5π/12, …
        ↓
  x = π/12 + πk   또는   x = 5π/12 + πk   (k = 0, 1, 2, …)
```

### 3-3. 점열 구조 (`pointset.js`)

* x 좌표가 등간격 → **y 값을 수열 분석기로 넘겨 일반항까지** 찾음
* 공선성 (전직교 회귀 — 수직선도 다룸)
* 이차곡선 적합 → 원·타원·포물선·쌍곡선 판별, **퇴화(두 직선·한 점)까지 구분**
  (식이 다항식이면 표본에 기대지 않고 **판별식을 유리수로 계산해 정확히** 가릅니다)
* 격자 배열, 좌우/상하/점/`y=x` 대칭
* 이웃 점 사이 거리의 규칙
* 닮음변환 규칙: 복소수로 `z_{k+1} = w·z_k + c` 를 최소제곱으로 풀어
  `|w|=1` 이면 **정다각형 회전**, `|w|≠1` 이면 **로그나선(등각나선)** 으로 판정

### 3-3-1. 곡선 자체의 기하 (`curve.js`)

식에서는 읽을 수 없고 **그려 봐야 아는 것들**입니다.

| 검사 | 방법 | 결과 예 |
|---|---|---|
| 닫힘 | 마지막 점이 첫 점으로 돌아오는가 | `r = 1+cos θ` → 닫힌 곡선 |
| 둘레 | 폴리라인의 길이 (반 픽셀까지 적응 세분한 표본) | 심장형 → 8 |
| 넓이 | 신발끈 공식 | 심장형 → 3π/2, `x⁴+y⁴=1` → 3.708 |
| 자기교차 | 격자에 담아 선분 쌍을 견줌 | `y² = x²(x+1)` → 원점에서 매듭 |

두 가지를 조심합니다.

* **되짚어 그리는 곡선.** `r = sin 3θ` 는 꽃잎 3장을 두 번씩 그립니다. 거의 겹친 두 경로가
  표본 잡음만큼 엇갈리며 수백 번 "교차"하는데, **15° 보다 얕게 만나면 세지 않습니다.**
  실제로 가로지르는 자리(장미의 원점 60°, 매듭의 원점 90°)는 훨씬 크게 벌어집니다.
  같은 자리에서 여러 번 만난 것도 하나로 묶습니다.
* **스스로 가로지르는 곡선의 넓이.** 신발끈 값이 상쇄되어 뜻이 흐려지므로 적지 않습니다.

화면 끝에 닿은 곡선은 "열려 있다"고 말하지 않고 *"보이는 부분의 길이"* 만 알립니다.

### 3-4. 억지로 규칙을 만들지 않기

분석기가 저지를 수 있는 가장 나쁜 실수는 **없는 규칙을 있다고 말하는 것**입니다.
그래서 다음 장치를 두었습니다.

* **확신도는 확인 횟수에서 나옵니다.** 항이 둘뿐이면 등차로도 등비로도 읽히므로
  둘 다 제시하고 "규칙을 정할 수 없음"이라고 밝힙니다. 확인이 쌓일수록 확신도가 올라갑니다.
* **정확한 규칙이 근사 모형보다 항상 앞섭니다.** 함수족 적합은 정확한 규칙이
  하나도 없을 때만, 그것도 확신도 0.6 이하로만 붙습니다.
* **값이 빠진 항**(NaN·발산)이 있으면 인덱스가 어긋나므로, 이어지는 가장 긴 구간만
  보고 몇 개를 뺐는지 밝힙니다.
* **겹친 점**은 먼저 걷어 냅니다. 같은 점 세 개를 "한 직선 위에 있다"고 말하지 않습니다.
* **상수함수·일차함수**는 f′ ≡ 0, f″ ≡ 0 이라 수치 미분의 잡음만으로도 "변곡점 2000곳"
  같은 결과가 나옵니다. 먼저 퇴화 여부를 판정해 걸러내고, 변곡점은
  **곡선이 자기 접선을 실제로 가로지르는지**로 다시 확인합니다.
* **해가 구간을 이루면**(예: `floor x` 는 [0,1) 전체가 해) 낱개의 점으로 세지 않고
  그렇다고 알립니다.
* **곡선에서 뽑은 표본은 점열이 아닙니다.** 표본이 놓인 차례와 간격은 표본화 방식이
  정한 것이라, 거기서 수열 규칙을 찾으면 `(cos t, sin 2t)` 의 x 좌표가 *"4계 선형
  점화식을 만족한다"* 는 말이 나옵니다. 곡선 표본에는 순서에 기대는 검사를 걸지 않습니다.
* **직선에 점근선을 붙이지 않습니다.** `y = 2x − 1` 은 자기 자신이 점근선이라 알릴 것이 없습니다.

### 3-5. 함수 성질 (`functionAnalysis.js`)

정의역 · 우함수/기함수 · 주기 · 실근 · 극대/극소 · 변곡점 · 단조성,
그리고 점근선을 찾습니다.

**극값은 이계도함수가 아니라 값으로 가릅니다.** `f″` 의 부호로 가르면 `y = −|x|` 의
꼭짓점은 `f″ ≡ 0` 이라 통째로 사라지고, `y = floor x` 의 뜀은 도함수가 튀어 없는 극값이
생깁니다. 대신 **양옆이 둘 다 엄격히 낮은지(높은지)** 를 보고, 간격을 4배 좁였을 때
낙차가 함께 줄어드는지 확인합니다. 매끄러운 극값은 `h²` 에 비례해 줄고, 뾰족점은 `h` 에
비례해 줄지만, 계단의 뜀은 줄지 않습니다. 봐 주는 폭은 값의 ulp 몇 배까지라
`y = 10¹⁰ − x²` 의 티끌 같은 낙차도 놓치지 않습니다.

**후보는 도함수의 영점만으로 모으지 않습니다.** `|sin x|` 의 `x = π` 에서 도함수는
−1 에서 +1 로 뛰기만 할 뿐 0 을 지나지 않습니다. 그래서 표본 배열에서 봉우리·골을 직접
집어 황금분할로 다듬은 뒤 후보에 더합니다 (`|sin x|` 의 극소 1개 → 5개).

**정의역은 구멍과 경계를 가릅니다.** `√x` 의 `x < 0` 은 구멍이 아니라 정의역 밖입니다.
표본 한두 칸짜리 빈틈만 구멍이라 부르고(`1/x` 의 `x = 0`), 넓은 빈틈은 경계로 보아
**이분법으로 좁힙니다** → *"x ≥ 0 에서만 정의됩니다"*, *"−1 ≤ x ≤ 1 에서만 정의됩니다"*.
화면 끝에 닿은 쪽은 경계가 아니므로 적지 않습니다.

점근선은 이렇게 찾습니다.

* **수직 점근선 = `1/f` 의 영점.** `tan x` 처럼 표본이 극점을 정확히 비껴가도 놓치지 않습니다.
* **수평 점근선**은 `|x|` 를 10⁵ → 10¹³ 로 키우며 값이 한 점으로 모이는지 확인합니다.
  여러 배율에서 모두 같은 값이어야 인정하므로, `sin x` 같은 진동 함수에
  **가짜 수평 점근선을 붙이지 않습니다.**
* 기울기가 남으면 사선 점근선으로 보되, **나머지 `f(x) − (mx+b)` 가 0 으로 줄어드는지**
  확인합니다. 상대오차로만 재고 정수 자리에서만 짚으면 `floor x` 도 `y = x` 를 점근선으로
  갖게 됩니다 — 나머지가 `(−1, 0]` 을 맴돌 뿐인데도요.

찾아낸 근은 다시 수열 분석기로 넘어가, `sin x` 의 근이 등차수열임을 스스로 알아냅니다.

## 4. 수식 처리 (`src/math/`)

* **파서** — Pratt 파서. 암묵적 곱(`2x`, `xy`, `3sin x`), 절댓값 `|x|`, 첨자 `a_{n−1}`,
  비교식, 논리 결합(`and`/`or`), 리스트 `{…}`, 점 `(a,b)`.
  괄호 없는 함수 호출은 `sin 2t → sin(2t)`, `sin x cos x → sin(x)·cos(x)` 로 갈라 읽습니다.
* **합·곱·정적분** — 속변수를 묶는 특수형을 지원합니다.
  `sum(k^2, k, 1, 10)`, `prod(k, k, 1, n)`, `integral(x^2, x, 0, 1)`, `integral(sin x, 0, pi)`.
  적분은 적응 심프슨법이고, 끝점이 특이하면 리만 합으로 물러섭니다.
  그래프에도 그대로 쓸 수 있습니다: `y = sum(x^k/fact(k), k, 0, 8)` (e^x 의 테일러 부분합)
* **컴파일러** — AST 를 클로저 트리로 바꿉니다. `eval`/`new Function` 을 쓰지 않아 안전하고,
  플로팅에 필요한 수십만 회 호출에도 충분히 빠릅니다.
* **기호 미분** — 극값·변곡점 탐색과 뉴턴법에 쓰입니다. 미분할 수 없는 식은 수치 미분으로 대체.
* **수 인식** — 연분수로 유리수를 복원하고 `π`, `√2`, `φ` 의 배수를 알아봅니다.
  결과가 `0.7853981…` 대신 `π/4` 로 나옵니다.

### 4-1. 기호(정확) 계산 층 (`math/rational.js`, `math/poly.js`, `analysis/exact.js`)

수치로는 **"정확히 0 인가"** 를 물을 수 없습니다. `x² + a y²= 1` 이 원이 되는 자리를
허용오차로 판정하면 `a = 0.9999` 도 원이 되고, 표본 간격보다 얇은 띠는 통째로 사라집니다.
그래서 식이 다항식이면 **BigInt 유리수 위의 다변수 다항식**으로 옮겨 정확히 다룹니다.

* **정확한 이차곡선 판정** — 판별식 `B²−4AC` 와 3×3 행렬식을 유리수로 계산합니다.
  `x²+y²=1` 은 원, `x²+1.0001y²=1` 은 타원, `y=x²` 는 포물선, `x²−y²=0` 은 두 직선 —
  **점 표본을 하나도 쓰지 않고** 가릅니다. 중심과 반지름²도 분수 그대로 나옵니다.
* **정확한 근** — 유리근 정리로 유리근을 뽑고 남은 이차식은 근호 꼴로 적습니다.
  `x²−x−1=0` → `(1−√5)/2`, `(1+√5)/2`. 통분·약분까지 해서 `(-2√2)/2` 같은 꼴을 남기지 않습니다.
* **분기점을 풀어서 구하기** — 파라미터가 든 식은 훑지 않고 **방정식을 세워 풉니다** (아래 5장).

무리수를 유리수라고 우기지 않는 것이 중요합니다. 배정밀도 실수는 어차피 전부 유리수라
"되돌렸을 때 값이 같은가" 만으로는 부족합니다 — π 도 분모를 8천만까지 키우면
`245850922/78256779` 로 정확히 맞아떨어집니다. 그래서 **분모 상한(10⁷)** 을 함께 겁니다.
사람이 소수로 적거나 슬라이더가 만드는 값은 분모가 그보다 작고, π·√2·e·ln2 는 걸러집니다.
상한을 넘으면 기호 계산이 **조용히 손을 떼고** 수치 경로로 돌아갑니다.

## 5. 파라미터 훑기 — 분류가 갈리는 지점 찾기

이 계산기에만 있는 기능입니다. 슬라이더 옆 **훑기** 를 누르면 파라미터를 처음부터 끝까지
움직이며 **해집합의 생김새가 바뀌는 자리**를 찾아 줍니다.

```
a = 1;  -2 <= a <= 2
x^2 + a y^2 = 1        ← 훑기
        ↓
  a ∈ [-2, 0]   쌍곡선
  a ∈ [0, 2]    타원
  분기점 a = 0        쌍곡선 → 타원   (이 값에서만: 두 평행선)
                     근거: 판별식 B²−4AC = 0, 퇴화 (행렬식 = 0), y² 항이 사라짐
  특이한 순간 a = 1    이 값에서만 원이 됩니다
```

찾아 주는 것들:

| 입력 | 알려 주는 것 | 근거 |
|---|---|---|
| `x^2 + a y^2 = 1` | 쌍곡선 → (두 직선) → 타원, 그리고 정확히 원이 되는 `a = 1` | `B²−4AC = 0`, `A = C` |
| `y = x^3 + a x` | 실근이 3개에서 1개로 바뀌는 `a = 0` | `Res(f, f′) = 0` |
| `y = a x^2 + x + 1` | 직선이 되는 `a = 0`, 실근이 사라지는 `a = 1/4` | 최고차항 `= 0`, 판별식 |
| `y = x^3 - 3x + a` | 실근이 1 → 3 → 1 로 바뀌는 `a = ±2` | `Res(f, f′) = 0` |
| `x^2 + y^2 = a` | 해 없음 → (한 점) → 원 이 되는 `a = 0` | 행렬식 `= 0` |
| `y = x^2 + a and y = x` | 연립해가 2개에서 0개로 바뀌는 `a = 1/4` | 판별식이 0 |
| `y = x^4 + a x^2` | 극값이 3개에서 1개로 바뀌는 `a = 0` | `Res(f′, f″) = 0` |
| `y^2 = x^3 - a x` | 가지가 1개에서 2개로 갈라지는 `a = 0` | (기호로 안 되어 훑기) |

### 어떻게 찾나 — ① 방정식을 세워 푼다

식이 다항식이면 훑기 전에 **분기점을 기호로 먼저 구합니다.** 표본 사이에 숨은 자리를
놓치지 않고, 답이 `0.2500001` 이 아니라 `1/4` 로 나오며, **왜 그 자리인지**까지 말할 수 있습니다.

| 식의 꼴 | 세우는 조건 | 뜻 |
|---|---|---|
| `A x² + Bxy + Cy² + Dx + Ey + F = 0` (계수가 `a` 의 다항식) | `B²−4AC = 0` | 타원 ↔ 쌍곡선이 갈리는 자리 |
| 〃 | 3×3 행렬식 `= 0` | 두 직선·한 점으로 무너지는 자리 |
| 〃 | `A = C` (그리고 `B = 0`) | 정확히 원이 되는 자리 |
| 〃 | `A = 0`, `C = 0` | 이차항이 사라져 직선·포물선이 되는 자리 |
| `y = f(x)` (계수가 `a` 의 다항식) | 종결식 `Res(f, f′) = 0` | 중근이 생겨 실근 개수가 바뀌는 자리 |
| 〃 | `Res(f′, f″) = 0` | 극값이 붙었다 떨어지는 자리 |
| 〃 | 최고차항 `= 0` | 차수가 떨어지는 자리 |

세운 조건은 `a` 에 대한 다항식이고, 그 실근을 유리근 정리 + 근호 꼴로 정확히 풉니다.
종결식은 실베스터 행렬의 행렬식을 **ℚ[a] 위에서 나눗셈 없이** 전개해 구하므로 오차가 없습니다.

```
y = a x² + x + 1
   Res(f, f′) = 4a² − a = a(4a − 1)   →   a = 0,  a = 1/4
        ↓
  a ∈ [-2, 0]    실근 2개 · 극값 1개
  a ∈ [0, 1/4]   실근 1개 · 극값 0개      ← 직선이 되는 구간
  a ∈ [1/4, 2]   실근 0개 · 극값 1개
```

수치로만 훑었을 때는 근이 화면 밖으로 나가는 자리(`22/169` 등)까지 분기점으로 잡혀
경계가 넷이었는데, 기호로 풀면 **수학적으로 의미 있는 둘**만 남습니다.

### 어떻게 찾나 — ② 훑어서 확인한다

기호로 풀 수 없는 식(`y = sin x + a`, `y² = x³ − a x` 등)은 여전히 훑습니다.
파라미터 t 마다 해집합에서 **연속적으로 변하지 않는 값**만 뽑아 서명(signature)을 만듭니다.
이차곡선의 종류, 곡선 가지 수, 고립해 개수, 실근·극값 개수 — 모두 어느 순간 툭 바뀌는 값들입니다.
서명이 달라지는 두 표본 사이를 **이분법으로 좁히면** 분기점 위치가 나옵니다.
기호로 구한 자리는 훑기 결과와 맞춰 보고, 같은 자리를 가리키면 **정확한 값으로 갈아 끼웁니다.**

서명을 만들 때 두 가지를 조심합니다.

* **종류를 알면 가지 수는 세지 않습니다.** 화면 밖으로 잘린 쌍곡선의 팔은 2개로도 4개로도
  세어져서, 분류가 그대로인데 경계가 있는 것처럼 보입니다.
* **표본 자리를 깔끔한 소수로 다듬습니다.** `min + span·i/(n−1)` 은 `-1.3999999999999999`
  같은 값을 냅니다. 눈으로는 `-1.4` 지만 유리수로 읽히지 않아 기호 계산 층이 손을 놓고,
  그러면 같은 구간 안에서도 표본마다 서명의 모양이 달라져 **없는 경계가 생깁니다.**
  유효숫자 12자리로 맞춰 `-7/5` 로 되돌려 놓습니다.

세 가지를 덧붙여 결과를 쓸 만하게 만들었습니다.

* **"그 순간"만 나타나는 모습** — 타원이 정확히 원이 되는 `a = 1`, 쌍곡선이 두 직선으로
  무너지는 `a = 0` 은 수학적으로 한 점입니다. 아주 좁은 구간으로 잡히면 별도의
  *특이한 순간* 으로 접어 보고합니다.
* **깔끔한 수로 맞추기** — 이분법이 짚은 자리는 방법의 분해능만큼 흔들립니다.
  `y = x³ + a x` 의 근 개수는 표본 간격보다 가까운 두 근을 구별하지 못해 `a = -8.6e-5` 로
  잡히지만, 훑는 범위의 0.1% 안에 깔끔한 수가 있으면 그것을 답으로 봅니다 → `a = 0`.
  맞추지 못한 값에는 *(근사)* 를 붙입니다.
* **구간의 대표 분류는 안쪽에서** — 경계 바로 옆은 두 모습이 섞이는 자리라 구간을
  대표하지 못합니다. 안쪽 세 곳에서 재어 가장 많이 나온 것으로 정하고, 다시 재고 나서
  이웃과 분류가 같아지면 **하나로 합칩니다.**

훑기는 **화면에 그릴 때와 같은 해상도**로 계산합니다. 성기게 훑으면 두 배쯤 빨라지지만,
원·두 평행선처럼 허용오차로 갈리는 분류의 경계가 눈으로 보는 것과 어긋납니다.
훑기가 알려 주는 분류는 화면에서 보이는 것과 같아야 하므로 속도보다 일치를 택했습니다.

표본 수는 **고정**합니다 (41개, 기호로 구한 분기점 후보가 있으면 21개). 걸리는 시간에
맞춰 줄이면 실행할 때마다 결과가 달라지고, 특히 "정확히 원이 되는 a = 1" 같은 얇은 띠를
통째로 건너뛰게 됩니다. 대신 이분법은
14번만 돌립니다 — 어차피 마지막에 깔끔한 수로 맞추므로(범위의 0.1%) 그보다 더 좁힐
실익이 없고, 맞추지 못한 값에만 *(근사)* 가 붙습니다.

계산이 무거우므로 **한 프레임에 12ms 어치씩** 나누어 돌립니다. 진행률이 버튼에 표시되고,
그동안에도 화면은 움직입니다. 시간 예산(6초)을 넘기면 남은 작업을 줄여서라도 결과를
돌려줍니다. 결과 카드를 누르면 그 값으로 슬라이더가 옮겨 가고,
슬라이더 아래에 분기점(빨강)과 특이한 순간(초록)이 눈금으로 남습니다.

## 6. 자료와 리스트 — 표 대신 리스트로

데스모스의 표·회귀에 해당하는 일을 리스트로 합니다.

```
x_1 = [0, 1, 2, 3, 4, 5, 6]
v_1 = [4, 5.95, 9.15, 14.4, 23.0, 37.6, 61.3]
(x_1, v_1)                    ← 자료를 점으로 찍는다
v_1 ~ c e^(k x_1) + d         ← 회귀:  c = 2.9496, k = 0.5028, d = 1.0606, R² = 0.999992
y = c e^(k x) + d             ← 찾은 계수를 그대로 써서 곡선을 그린다
```

회귀는 **Levenberg–Marquardt** 로 풉니다. 모형이 계수에 대해 선형이든 아니든 같은 방식으로
맞출 수 있어서 `y_1 ~ a x_1 + b` 도, `v_1 ~ c e^(k x_1) + d` 도 그대로 됩니다.
아직 정의되지 않은 이름을 미지의 계수로 보고, 찾은 값은 다른 식에서 바로 쓸 수 있게
등록합니다. R²·RMSE·잔차도 함께 보여 줍니다.

리스트는 이렇게 만듭니다.

| 쓰는 법 | 뜻 |
|---|---|
| `[1, 2, 3]` | 그냥 리스트 |
| `[1...10]` | 1 부터 10 까지 |
| `[1, 3, ..., 11]` | 간격이 2 인 범위 |
| `[n^2 for n = [1...5]]` | 리스트 내포 → `[1, 4, 9, 16, 25]` |
| `[1,2,3] + 10`, `[1,2,3]^2`, `sin([0, π])` | 원소마다 계산 |
| `mean · median · stdev · total · length · sort · quantile · max · min` | 통계 |

식의 값이 리스트면 **곡선이 여러 개 그려집니다**: `y = [1, 2, 3] x` 는 기울기가 다른 직선 셋.

## 7. 조각별 정의와 정의역 제한

```
y = x^2 {0 < x < 3}      조건이 참인 곳에만 그린다
y = {x < 0: -x, x^2}     조각별로 다른 식
y = x {x<0: -1, 1}       값이 있는 중괄호는 곱셈 (부호함수를 곱한 꼴)
```

값 없이 조건만 있는 중괄호는 **제한**, 값이 있는 중괄호는 **조각별 식(곱해지는 인수)** 으로
갈라 읽습니다.

## 8. 손으로 굴려 보기

* **슬라이더** — `a = 2` 라고 쓰면 값 아래에 슬라이더가 붙습니다. 끌면 그 값을 쓰는 식이
  함께 움직입니다. 범위는 값에서 유추하고, `a = 2; 0 <= a <= 5` 로 직접 정할 수도 있습니다.
* **교점 (∩)** — 화면에 있는 곡선들이 만나는 점을 모두 찾아 표시하고,
  **곡선 쌍마다 따로** 분석합니다. 여러 쌍의 교점을 한 덩어리로 섞으면 규칙이 묻히기 때문입니다.
  `y = sin 2x` 와 `y = 0.5` 를 함께 올리고 ∩ 를 누르면
  `x = π/12 + πk 또는 x = 5π/12 + πk` 가 나옵니다 — 그래프에서 읽어 낸 삼각방정식의 해입니다.
* **점열 만들기** — `P_n = (n, 2^n); 1 <= n <= 8` 처럼 점열을 직접 정의할 수 있습니다.
  `Q_k = (cos(2πk/7), sin(2πk/7)); 0 <= k <= 6` 이면 정7각형과 회전 규칙까지 읽어 줍니다.
* **도함수** — `f(x) = x^3 - 3x` 를 정의해 두면 `y = f'(x)`, `y = f''(x)` 를 그릴 수 있습니다.
* **저장과 공유 (🔗)** — 화면 상태가 주소창에 담겨 자동 저장됩니다. 링크를 복사해 그대로
  건네면 같은 화면이 열립니다. 새로 고쳐도 하던 작업이 남아 있습니다.
* **겉모습 지정** — 왼쪽 색 띠를 누르면 색 12가지·굵기·진하기·선 모양(실선/파선/점선)·
  점 모양(채움/테두리/네모/×)·점 크기를 고를 수 있습니다. 링크에도 함께 담깁니다.
* **훑기** — 파라미터를 훑으며 분류가 갈리는 지점을 찾습니다 (위 5장).
* **슬라이더 자동 재생** — ▶ 를 누르면 값이 저절로 훑어집니다. ↻ 는 끝에서 처음으로,
  ↔ 는 끝에서 되돌아옵니다. 계산이 무거우면 프레임을 건너뛰어 끊기지 않게 합니다.
* **점 끌기** — `a = 1; b = 2` 를 정의하고 `(a, b)` 를 찍으면 그 점을 **직접 끌 수** 있습니다.
  끄는 동안 슬라이더와 그 값을 쓰는 모든 식이 함께 움직입니다.
* **각도 단위** — `π` 버튼으로 라디안 ↔ 도(°)를 오갑니다. `sin(90) = 1` 처럼 씁니다.
* **수식 표시** — 입력한 식을 아래에 수학처럼 다시 그립니다. 분수는 위아래로 쌓고,
  지수는 위첨자로, 근호에는 웃선을 씌웁니다 (LaTeX 엔진 없이 HTML 만으로).
* **두 손가락 확대** — 터치 화면에서 핀치로 확대·축소할 수 있습니다.
* **x·y 축 따로 확대** — shift+휠은 세로만, alt+휠은 가로만 늘립니다. `□` 로 1:1 로 되돌립니다.
  `y = 1000x` 나 항이 수천까지 커지는 수열도 화면에 담깁니다 (`⤢` 는 축 비율을 따로 잡아 맞춥니다).
* **되돌리기** — Ctrl+Z / Ctrl+Shift+Z. 식 사이는 ↑·↓ 로 옮겨 다닙니다.
* **분석 결과 복사** — 분석 패널의 `복사` 로 찾아낸 내용을 글로 옮겨 붙일 수 있습니다.

## 9. 다루기

무거운 음함수가 여럿 올라와 있으면 한 번의 재계산이 수백 ms 걸립니다. 그래서
**끌거나 확대하는 동안에는 다시 풀지 않고** 이미 구해 둔 해집합을 그대로 그립니다.
해집합은 수학 좌표로 저장되어 있어 화면 변환만 바뀌면 그림은 그대로 맞고,
손을 놓은 뒤에 한 번만 다시 풉니다 (드래그 프레임 400ms → 3ms). 가장자리가 비어
보이지 않도록 보이는 영역보다 12% 넓게 계산해 둡니다.
